# Artwork license and replacement guide

The artwork in this directory was created by **Spiders.n.ciders**.

It is included so the original Eye Catcher demonstration can be played, but it is not covered by the repository's MIT software license. Do not reuse, redistribute, remix, or publish these artwork files in another project without separate permission from the artist.

## Creating your version

Replace every artwork file in this directory with your own work before distributing or publishing a customized version. The easiest method is to keep the existing filenames. The game automatically scales sprite artwork, so exact pixel dimensions are not required.

If you use different filenames or formats, update the paths in [`../config.js`](../config.js).
